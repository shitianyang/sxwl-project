# 数行未来 UI 设计规范 v2.0

> 定位：**UI 规范是地基，美化必须建立在规范之上**。本规范统一「Web 端（sxwl-react / 权限平台）」与「移动端（sxwl-uniapp / 小程序）」的品牌视觉基础。任何页面美化不得脱离本规范临时发挥。
>
> 版本：v2.0 · 2026-08-21 · 维护：小U / 老板
> 可视化版本：`sxwl-design-system.html`（设计规范原型）

---

## 1. 设计原则

| 编号 | 原则 | 说明 |
|---|---|---|
| 1.1 | 规范先行，美化在后 | 任何页面先符合本规范，再谈好看 |
| 1.2 | 品牌一致，两端分治 | 同一品牌橙，Web 端克制使用，移动端可氛围化使用 |
| 1.3 | 同一品牌 token | 两端共享同一套色板/字号/间距/圆角基准，差异只在应用强度与组件形态 |
| 1.4 | Web 端克制 | 后台是效率工具：中性底色 + 白卡片 + 细边框，橙色占比 < 10% |
| 1.5 | 移动端亲和 | 小程序是 C 端工具：允许橙金渐变、玻璃质感与轻动效，橙色占比可达 30%~40% |

## 2. 色彩规范

### 2.1 品牌橙主色阶

| 阶 | 色值 | 用途 |
|---|---|---|
| 50 | `#FFF7E6` | 浅底 / 选中底 |
| 100 | `#FFE7BA` | 浅描边 |
| 200 | `#FFD591` | Hover 底 |
| 300 | `#FFB76B` | Hover 边 |
| 400 | `#F0972D` | 渐变亮色 |
| **500（主）** | **`#DE5F0E`** | **品牌主色：主按钮/选中/链接** |
| 600 | `#C74E08` | Active 按下 |
| 700 | `#A83E06` | — |
| 800 | `#8A3205` | 深色文字 |

### 2.2 中性色阶

| 阶 | 色值 | 用途 |
|---|---|---|
| 1 | `#1F2329` | 主文字 |
| 2 | `#4E5969` | 次级文字 |
| 3 | `#86909C` | 弱化文字 |
| 4 | `#C9CDD4` | 占位 / 禁用 |
| 5 | `#E5E6EB` | 分割线 |
| 6 | `#F2F3F5` | 悬停底 |
| — | `#FFFFFF` | 卡片底 |
| — | `#F0F2F5` | **Web 页面底** |
| — | `#F6F7F9` | **移动页面底** |

### 2.3 功能色

| 语义 | 色值 | 说明 |
|---|---|---|
| 成功 | `#00B578` | 绿 |
| 警告 | `#FF9F0A` | 橙黄 |
| 错误 | `#FF4D4F` | 红 |
| 信息 | `#1677FF` | 蓝 |

### 2.4 橙色使用规则（关键）

- **Web 端（克制）**：橙 = 功能主色，仅用于主按钮 / 菜单选中 / 链接 / 分页当前页 / 1~2 个关键指标。**禁止**大面积渐变底、玻璃光斑、金橙发光文字。
- **移动端（氛围）**：橙 = 品牌氛围，允许 Hero 渐变、金额渐变发光、主操作、选中态、金橙辉光（#FFC53D 系列）；表单/列表主体保持中性。

## 3. 字体规范

- 字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`；数字建议 `tabular-nums`。
- 字号阶（Web 正文 14 / 移动正文 16）：

| 用途 | 字号 / 字重 |
|---|---|
| 页面大标题 | 30 / 800 |
| 区块标题 | 24 / 800 |
| 卡片标题 | 20 / 700 |
| 移动页标题 | 16 / 700 |
| Web 正文（基准） | 14 / 400 |
| 表格 / 表单（Web） | 13 / 400 |
| 辅助说明 | 12 / 400 |

- 字重：正文 400 / 强调 500 / 标题 600 / 大数字 800；禁止非必要斜体与装饰字体。

## 4. 间距规范

以 4px 为基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。两端共用同一基准。

| 档位 | 用途 |
|---|---|
| 4 | 微间距 |
| 8 | 紧凑 |
| 12 | 控件间 |
| 16 | 卡片内 |
| 20 | 内容区 |
| 24 | 区块间 |
| 32 | 页面留白 |
| 40 / 48 | 大区块 / 极致留白 |

## 5. 圆角规范

Web 偏锐利、移动偏圆润：

| 圆角 | 用途 |
|---|---|
| 4 | Web 徽标 |
| 6 | Web 按钮 |
| 8 | Web 输入 / 表格 |
| 10 | 移动控件 |
| 12 | Web 卡片 |
| 14 | 移动列表卡 |
| 20 | 移动 Hero / 卡片 |
| 999 | 标签 / 胶囊 |

## 6. 阴影规范

| 层级 | 值 | 用途 |
|---|---|---|
| L1 | `0 1 2 / 0 1 3 rgba(0,0,0,.04)` | 卡片常驻 |
| L2 | `0 4 12 / 0 2 6 rgba(0,0,0,.08)` | 悬浮反馈 |
| L3 | `0 18 44 / 0 6 16 rgba(0,0,0,.14)` | 弹层浮起 |

Web 用中性黑投影；移动端允许品牌橙投影（氛围）。

## 7. 组件规范

| 组件 | 规范 |
|---|---|
| 按钮 | 主按钮（橙）一屏 ≤ 1 个；次按钮灰边；危险操作红色；尺寸：大 42 / 中 32 / 小 28 |
| 输入框 | 聚焦态：橙描边 + 3px 橙光晕（rgba(222,95,14,.10)）；禁用态浅灰底 |
| 标签 | 胶囊形；实时=橙、启用=绿、停用=灰、错误=红 |
| 表格 | 表头浅灰底 #FAFAFA、行 hover #FAFAFA、操作列橙色文字链接、分页当前页橙 |

- Web 端由 antd + ConfigProvider token 驱动；移动端由 uni.scss 变量驱动。

## 8. 布局骨架

| 端 | 骨架 |
|---|---|
| Web | 侧边导航 208 + 顶栏 52（白底，面包屑 + 右侧操作区）+ 内容区浅灰底 #F0F2F5（padding 20，页头 + 搜索卡 + 表格卡） |
| 移动 | 状态栏 44 + 顶部导航 44（标题居中）+ 内容 + 底部 TabBar 60（图标 + 文字，激活态橙色渐变） |

## 9. 动效规范

| 端 | 规范 |
|---|---|
| Web | hover 150ms / 展开 200ms / 弹窗 300ms；仅位移 + 透明度，禁旋转弹跳 |
| 移动 | 入场 400ms fade-up、数字滚动 800ms easeOutCubic、按钮按压缩放 0.96 |

- 关键帧命名：Web 统一 `sxwl-` 前缀；移动统一放 uni.scss。

## 10. 两端差异对照

| 维度 | Web 端（B 端） | 移动端（C 端） |
|---|---|---|
| 橙色强度 | 功能主色，< 10%，无大面积渐变 | 品牌氛围，允许渐变/辉光/玻璃 |
| 页面底色 | #F0F2F5 | #F6F7F9 / 暖白渐变 |
| 圆角 | 控件 6 · 卡片 8–12 | 控件 10 · 卡片 14–20 |
| 阴影 | 中性黑投影 | 允许品牌橙投影 |
| 正文基准 | 14px（表格 13px） | 16px（rpx 换算） |
| 导航 | 侧边 208 + 顶栏 52 | 顶部 44 + TabBar 60 |
| 动效 | 150–300ms 克制 | 200–400ms + 滚动/按压 |
| 组件来源 | antd + token | uni-app + scss 变量 |
| 装饰 | 禁止玻璃/霓虹/粒子 | 允许轻玻璃/光斑/噪点（克制） |

## 11. 栅格与响应式

- Web：24 栅格（antd Row/Col），内容区按 2 / 3 / 4 / 6 分栏。
- 断点（与 antd 对齐）：xs <576 单列 / sm ≥576 / md ≥768 2 列 / lg ≥992 4 列 / xl ≥1200 / xxl ≥1600 6 列。
- 移动：设计稿 750 宽，1rpx = 0.5px；内容单列为主，卡片间距 24rpx，页边距 32rpx。

## 12. 表单规范

- Web：弹窗表单一行 2 列（12 栅格），搜索表单一行 3~4 列；标签固定 100px 左对齐，必填红 * 前置。
- 移动：标签在控件上方（垂直表单），一行一字段。
- 错误态：字段下方 12px 红字提示 + 输入框红边（#FF4D4F），错误解除即消失。

## 13. 反馈体系

| 形态 | 规范 |
|---|---|
| 消息 Message | 成功绿 / 错误红 / 警告橙黄 / 信息蓝，白底 + 彩色圆点 |
| 弹窗 Modal（Web） | 宽 416，标题 + 分隔线 + 底部右对齐「取消 / 确定（橙）」，圆角 8，遮罩黑 45% |
| 弹层（移动） | ActionSheet 上圆角 20；居中卡片圆角 16 |
| 空状态 | 图标 + 文案 + 建议操作 |
| 加载 | 首屏骨架屏 / 局部行内 loading / 全屏遮罩 spinner；>2s 展示进度 |

## 14. 图标规范

- 尺寸：菜单/表格 16 · 按钮 16 · 页面主视觉 24 · 空态 32+（Web 空态 48）。
- 风格：线型、圆角端点、笔画 1.5–2px。
- 来源：Web 统一 `@ant-design/icons`（经 SxwlIcon 封装），禁止散落硬编码 SVG；移动 TabBar 24×24、列表图标 40rpx，emoji 仅用于分类/装饰语义。

## 15. 页面模板

| 模板 | 结构 |
|---|---|
| 列表页（标准 CRUD） | 页头（标题 + 描述 + 主操作=橙）→ 搜索卡 → 表格卡 → 分页；由 SxwlPage 提供 |
| 弹窗表单 | 宽 416，一行 2 列；由 SxwlFormModal 提供 |
| 登录页 | 居中卡片：Logo（橙）+ 平台名 + 副标题 + 表单 + 底部版权 |
