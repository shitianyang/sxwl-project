#### 2.2.2 SecurityContext 同步处理

```java
// 在请求线程同步取出 userId/orgId，传入异步方法
SxwlLoginUser loginUser = SxwlSecurityUtils.getCurrentUser().orElse(null);
Long userId = loginUser != null ? loginUser.getUserId() : null;
Long orgId = loginUser != null ? loginUser.getOrgId() : null;
sysBackupService.backup(userId, orgId);
```

✅ **关键验证**: 避免了异步线程无 SecurityContext 导致 `sys_file_info` 审计字段为 NULL 的问题

#### 2.2.3 前端 API（backupApi.ts，46 行）

**类型定义**:
- ✅ `SysBackupItem` - 备份记录 DTO（含 `fileSizeDisplay` 格式化字段）
- ✅ `PageInfo<T>` - 分页响应类型

**接口函数**:

### 2.3 核心亮点
