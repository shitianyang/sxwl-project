## 1. 认证与安全

### 1.1 用户认证（Auth）

**模块路径**：`sxwl-boot-module-auth`  
**API 前缀**：`/auth`

| 功能 | 接口路径 | HTTP 方法 | 权限标识 | 说明 |
|------|---------|----------|---------|------|
| 密码登录 | `/auth/login/password` | POST | - | 用户名+密码登录，SM2 加密传输 |
| 短信登录 | `/auth/login/sms` | POST | - | 手机号+验证码登录 |
| 微信登录 | `/wx-auth/wechat-miniprogram-login` | POST | - | 微信小程序码登录 |
| Token 刷新 | `/auth/refresh` | POST | - | 使用 refresh_token 续期 |
| 退出登录 | `/auth/logout` | POST | - | 使当前 token 失效 |
| 获取当前用户权限 | `/auth/permissions` | GET | - | 返回角色码和权限码列表 |
| 获取公钥 | `/auth/public-key` | GET | - | 获取 SM2 公钥用于前端加密 |
| 获取图形验证码 | `/captcha/image` | GET | - | 生成验证码图片 |

**安全特性：**
- ✅ JWT Token 双令牌机制（access_token + refresh_token）
- ✅ SM2 国密算法加密传输
- ✅ 密码强度校验（最小长度 ≥8，复杂度要求）
- ✅ BCrypt/SM3 哈希存储，随机 salt
- ✅ 暴力破解防护（连续失败锁定 + 验证码）
- ✅ 单用户并发登录限制（可配置）

| 功能 | 接口路径 | HTTP 方法 | 权限标识 | 说明 |
|------|---------|----------|---------|------|
| 简单上传 | `/rustfs/file/simple` | POST | `system:file:upload` | 小文件不分片上传 |
| 初始化分片上传 | `/rustfs/file/upload/init` | POST | `system:file:upload` | 大文件分片上传初始化 |
| 上传分片 | `/rustfs/file/upload/chunk` | POST | `system:file:upload` | 上传文件分片 |
