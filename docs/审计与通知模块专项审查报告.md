#### ✅ ServiceImpl 实现（SysNoticeInfoServiceImpl）

**核心实现**：

```java
@Service
public class SysNoticeInfoServiceImpl implements SysNoticeInfoService {
    
    private final SysNoticeInfoMapper noticeMapper;
    private final SysNoticeReadMapper readMapper;
    private final SxwlSseEmitterManager sseEmitterManager;
    
    @Override
    public void publishNotice(Long id) {
        // 1. 更新状态为已发布
        SysNoticeInfo notice = new SysNoticeInfo();
        notice.setId(id);
        notice.setStatus(1);
        noticeMapper.updateById(notice);
        
        // 2. SSE 实时推送
        broadcastPublish(id);
    }
    
    @Override
    public void broadcastPublish(Long noticeId) {
        SysNoticeDTO notice = getNoticeById(noticeId);
        
        // 发送给所有在线用户
        for (Map.Entry<Long, List<SseEmitter>> entry : sseEmitterManager.getEmitterMap().entrySet()) {
            Long userId = entry.getKey();
            List<SseEmitter> emitters = entry.getValue();
            
            for (SseEmitter emitter : emitters) {
                try {
                    emitter.send(SseEmitter.event()
                        .name("notice_published")
                        .data(notice));
                } catch (IOException e) {
                    log.error("发送 SSE 消息失败", e);
                }
            }
        }
    }
}
```

### 6️⃣ SSE 实时推送验证

#### ✅ 后端 SSE 架构

**SseEmitterManager**（核心管理器）：

```java
@Component
public class SxwlSseEmitterManager implements DisposableBean {
    
    private static final long SSE_TIMEOUT_MS = 24 * 60 * 60 * 1000; // 24 小时
    
    /** userId → [SseEmitter, ...]（支持多标签页） */
    private final Map<Long, List<SseEmitter>> emitterMap = new ConcurrentHashMap<>();
    
    /**
     * 建立 SSE 连接
     */
    public SseEmitter connect(Long userId) {
        SseEmitter emitter = new SseEmitter(SSE_TIMEOUT_MS);
        
        // 超时回调
        emitter.onTimeout(() -> {
            List<SseEmitter> emitters = emitterMap.remove(userId);
            if (emitters != null) {
                emitters.forEach(SseEmitter::complete);
            }
        });
        
        // 错误回调
        emitter.onError(e -> {
            log.error("SSE 连接出错", e);
            emitterMap.remove(userId);
        });
        
        // 注册连接
        List<SseEmitter> emitters = emitterMap.computeIfAbsent(userId, k -> new ArrayList<>());
        emitters.add(emitter);
        
        return emitter;
    }
    
    /**
     * 广播消息给指定用户的所有设备
     */
    public void sendMessage(Long userId, Object data) {
        List<SseEmitter> emitters = emitterMap.get(userId);
        if (emitters == null || emitters.isEmpty()) {
            return; // 用户不在线
        }
        
        for (SseEmitter emitter : emitters) {
            try {
                emitter.send(SseEmitter.event()
                    .name("notice_published")
                    .data(data));
            } catch (IOException e) {
                log.error("发送 SSE 消息失败", e);
            }
        }
    }
}
```
